# Synthetic Data
This project simulates realistic synthetic channel data for analytics practice, SQL testing, and marketing portfolio projects.

## Long-Term Simulation
> 💡 The randomness is locked at **seed 92**, creating a permanent save point that keeps IDs and relationships consistent for ERDs, joins, and relational databases. This ensures that the dataset to evolve consistently over time.

---

### Core Features
* **Timeline Logic:** Tiktok marketplace was launched in Thailand in June 2022.
* **Prefixes:** Channel ID uses a short 4-character UUID with the `CH_` prefix to keep records organized and easy to connect across tables.
