# Synthetic Data
This project simulates realistic synthetic product data for analytics practice, SQL testing, and marketing portfolio projects.

## Long-Term Simulation
> 💡 The randomness is locked at **seed 92**, creating a permanent save point that keeps IDs and relationships consistent for ERDs, joins, and relational databases. This ensures that the dataset to evolve consistently over time.

---

### Core Features
* **Dynamic Mapping:** Prices and weights automatically match the exact combination of a product's type and size (like assigning a specific price only for a King-sized Pocket Spring Mattress).
* **Automatic Variation:** Takes basic product categories and multiplies them across every size and color combination to instantly create a full product list.
