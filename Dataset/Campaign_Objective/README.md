# Synthetic Data
This project simulates realistic synthetic Campaign and Objective bridge table for analytics practice, SQL testing, and marketing portfolio projects.

---

### Core Features
* **Many to Many Relationship:** Built because one marketing campaign can have multiple business goals at once like running a 10.10 Flash Sale to hit both a revenue target and increase repeat customer purchases.
* **Realistic Business Rules:** Links campaigns and goals based on actual marketing logic (matching specific campaign names and types to the right objectives) instead of just using random data.
* **Timeline Safety Guard:** Keeps dates historically logical. Since company goals change and grow over time, the code makes sure a campaign can never connect to a corporate goal that didn't exist yet when the campaign went live.
