# Synthetic Data
This project simulates realistic synthetic order status data for analytics practice, SQL testing, and marketing portfolio projects.

## Long-Term Simulation
> 💡 The randomness is locked at **seed 92**, creating a permanent save point that keeps IDs and relationships consistent for ERDs, joins, and relational databases. This guarantees that the core product categorizations stay entirely deterministic during catalog expansions.

---

### Core Features
* **Prefixing:** Primary keys utilize a `STAT_` layout ruleset to cleanly distinguish transactional dimensional constraints from structural keys.
